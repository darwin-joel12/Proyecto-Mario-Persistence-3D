# Juego Mario 3D - Persistencia de Datos

Proyecto desarrollado para la asignatura de Ingeniería en Software. Implementa persistencia de datos entre Unity y MySQL.

## Estructura de entrega:
- **/Scripts**: Código fuente en C# del controlador de personaje.
- **/Backend**: Lógica del servidor (game.php).
- **/Database**: Archivo de exportación (.sql) para la configuración de MySQL.

## Funcionalidades implementadas:
- Guardado de posición 3D (X, Y, Z + Rotación Y).
- Auto-guardado inteligente (tiempo/distancia).
- Sistema de Ranking Global (Top 10).
- Gestión de inventario persistente.
